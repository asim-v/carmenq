# CARMEN-Q brand

**CARMEN-Q** expands to *Causal Audit-Return Memory Evaluation and Numerics for Quantum Processes*.

The enclosing Q represents a coherent temporal memory. The amber and teal paths share a committed prefix before separating into AUDIT and RETURN. The central dot is the persistent qubit.

The primary palette is midnight navy `#102A43`, audit amber `#F2A93B`, return teal `#18A999`, and neutral slate `#526777`. The mark must not be recolored in a way that makes AUDIT and RETURN indistinguishable.

The generated visual exploration that informed this identity used OpenAI's image-generation tool. The committed SVG files are simplified, deterministic vector artwork suitable for documentation and software distribution.
