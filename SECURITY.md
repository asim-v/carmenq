# Security and scientific-integrity reports

For software vulnerabilities, please avoid posting exploit details in a public issue. Send a concise report to `bazan@ciencias.unam.mx` with the affected version, reproduction steps, and expected impact.

Errors in the theorem, implementation, statistical certificate, or access-model assumptions are scientific-integrity issues rather than conventional security vulnerabilities. They may be reported publicly through GitHub Issues when disclosure does not create a software security risk. A useful report includes the precise claim, a minimal counterexample or failing test, and the environment needed to reproduce it.

No response-time or embargo guarantee is currently offered. This is an academic research project, not a safety-critical or production control system.
