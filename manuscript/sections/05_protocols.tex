\section{Statistical certificate and experimental protocol}
\label{sec:protocol}

The theorem gives a probability bound. An experiment needs a fixed analysis rule that accounts for finite samples and declared model uncertainty.

\subsection{Fixed-sample certificate}

Let $(K_{\mathrm A},N_{\mathrm A})$ and $(K_{\mathrm R},N_{\mathrm R})$ be successes and fixed trials in the two branches. Define
\[
\widehat S=\lambda\frac{K_{\mathrm A}}{N_{\mathrm A}}
+(1-\lambda)\frac{K_{\mathrm R}}{N_{\mathrm R}}.
\]
For independent Bernoulli trials, the one-sided weighted Hoeffding radius is
\begin{equation}
r_\alpha=
\sqrt{\frac12\left(
\frac{\lambda^2}{N_{\mathrm A}}+
\frac{(1-\lambda)^2}{N_{\mathrm R}}
\right)\log\frac1\alpha}.
\label{eq:hoeffding}
\end{equation}
Before observing outcomes, let $\delta_{\mathrm A}$ and $\delta_{\mathrm R}$ upper-bound possible upward bias in the two estimators, and let $\delta_{\mathrm{null}}$ enlarge the theoretical null for source, isolation, and interface uncertainty. We certify incompatibility with the declared classical-memory null only if
\begin{equation}
\widehat S-lambda\delta_{\mathrm A}
-(1-\lambda)\delta_{\mathrm R}-r_\alpha
>\Cstream+\delta_{\mathrm{null}}.
\label{eq:certificate}
\end{equation}
Under the stated independent fixed-sample model, the false-positive probability is at most $\alpha$. Choosing $n$ or $\lambda$ after seeing data, optional stopping, or reporting the best of several lengths requires corrections not supplied by \eqref{eq:certificate}.

For an alternative score $S_{\mathrm{alt}}$, define
\[
g=S_{\mathrm{alt}}-\lambda\delta_{\mathrm A}
-(1-\lambda)\delta_{\mathrm R}
-\Cstream-\delta_{\mathrm{null}}.
\]
If $g\leq0$, no amount of data certifies the claim under those allowances. If $g>0$, fixed sample sizes satisfying $r_\alpha+r_\beta<g$ guarantee power at least $1-\beta$ by a second Hoeffding bound. The implementation allocates trials asymptotically as $N_{\mathrm A}:N_{\mathrm R}=\lambda:(1-\lambda)$.

\subsection{Commitment and branch timing}

A valid trial executes in this order:
\begin{enumerate}
  \item prepare and independently characterise $n$ EPR sources;
  \item release $A_i$ only after $B_{i-1}$ has entered trusted sequestration;
  \item after $B_n$, require delivery of the terminal memory port $M$;
  \item generate the hidden AUDIT/RETURN choice;
  \item apply the preregistered branch decoder and binary acceptance measurement;
  \item record every loss and exclusion under a predeclared rule.
\end{enumerate}
The branch choice may be randomised per trial, but the final branch counts and stopping rule must be fixed or analysed with a sequentially valid method.

\subsection{Mandatory shortcut controls}

\begin{enumerate}
  \item \textbf{Dephased memory:} deliberately dephase the persistent carrier between slots.
  \item \textbf{Strong classical record:} measure every event and retain its transcript; AUDIT should improve while global RETURN falls.
  \item \textbf{Collective access:} remove sequestration and verify the higher curve \eqref{eq:collective}.
  \item \textbf{Output revisit:} return an earlier $B_i$ to the device, demonstrating why the causal boundary matters.
  \item \textbf{Decoder null:} replace the coherent inverse with identity or a mismatched inverse.
  \item \textbf{Source and measurement calibration:} bound false EPR acceptance and parity bias independently.
  \item \textbf{Blind branch choice:} test for branch information leaking before commitment.
  \item \textbf{Side-channel audit:} bound coherent transfer through buses, pulse tails, clocks, resonators, unused levels, and shared ancillas.
\end{enumerate}

The null does not forbid inaccessible erasure environments. Consequently, visible reset of $M$ is a reproducibility and wiring check, not a certificate that every physical copy of a classical transcript has vanished.

\subsection{Reproducible analysis interface}

The public implementation exposes three strict-JSON commands:
\begin{verbatim}
audit-return-benchmark bound --steps 8
audit-return-benchmark plan --steps 8 --forecast-model
audit-return-benchmark analyse --steps 8 \
  --audit-successes 9700 --audit-trials 10000 \
  --return-successes 9500 --return-trials 10000
\end{verbatim}
Systematic allowances, $\alpha$, $\beta$, and null slack are command-line inputs and appear in the output. An example preregistration records the terminal port, source calibration, decoder, exclusions, controls, and stopping rule.
