\section{Reproducibility specification}
\label{app:reproducibility}

The release artifact uses Python 3.10.5, NumPy 2.2.6, SciPy 1.15.3, Matplotlib 3.10.9, and pytest 9.1.1. From the repository root:
\begin{small}
\begin{verbatim}
python -m pip install -e ".[dev,reproducibility]"
python -m pytest -q
python scripts/regenerate.py \
  --seed 20260812 --shots 8192
python scratch/originality_gate/\
  validate_streaming_parity.py
python scripts/build_pdf.py
\end{verbatim}
\end{small}

The committed outputs include \texttt{data/audit\_return\_frontier.csv}, with 606 exact support rows spanning six stream lengths and 101 weights, and \texttt{data/audit\_return\_forecast.csv}, with 200 planning rows under the declared example law. The corresponding vector figures are \texttt{audit\_return\_frontier.pdf} and \texttt{audit\_return\_benchmark.pdf}. Stored adversarial searches appear in \texttt{streaming\_parity.json}, while \texttt{streaming\_parity\_validation.json} records the fast independent validation summary.

Timestamps in generated figure PDFs are suppressed for deterministic same-environment generation. The manuscript PDF records its build time. Raster and vector rendering can differ across operating systems because of font and rendering-library versions; numerical CSV drift is the stronger cross-platform invariant.

The forecast does not simulate a specific device's density matrix. It evaluates the exact theorem and statistical planner under \eqref{eq:forecast}. Experimental use must replace its probabilities with measured or independently calibrated values.
